# Best Home Properties — Listings Website

Public listings site for Best Home Properties (Abu Dhabi & Dubai), hosted free on GitHub Pages.

- `index.html` / `styles.css` / `app.js` — the site
- `listings.json` — all live listings (edit this to add/remove/update)
- `photos/<CODE>/` — listing photos (cover image referenced in `listings.json`)

Rules: never show prices on this site, never show owner numbers — only the
agent's WhatsApp (+971 56 420 5848). Keep wording rent/sale-neutral.
